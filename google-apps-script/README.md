# เชื่อมแอปกับ Google Sheet (ทำครั้งเดียว ~5 นาที)

Google Sheet: https://docs.google.com/spreadsheets/d/10Hv9bbHymylP5WU-2Zd-kQ8aCKCUf9KcT10v0XTpClg/edit
(เจ้าของ: nae.nitis9999@gmail.com)

## 1) ติดตั้งสคริปต์
1. เปิด Sheet > **Extensions > Apps Script**
2. ลบโค้ดเดิม วางเนื้อหา `Code.gs` ทั้งหมด
3. แก้ `const API_KEY = 'CHANGE_ME'` เป็นรหัสที่คุณตั้งเอง (ยาวๆ สุ่มๆ)
4. เลือกฟังก์ชัน **setup** > กด **Run** > อนุญาตสิทธิ์
   → จะสร้างแท็บ `Summary`, `Rooms`, `Tenants`, `Transactions` พร้อมหัวตาราง ตัวกรอง dropdown สีสถานะ และสูตรสรุป

## 2) Deploy เป็น API
**Deploy > New deployment > Web app**
- Execute as: **Me**
- Who has access: **Anyone**

คัดลอก URL (ลงท้าย `/exec`)

## 3) ตั้งค่าบน GitHub (repo Nae0000/Pms > Settings > Secrets and variables > Actions)
| ประเภท | ชื่อ | ค่า |
|---|---|---|
| Variable | `SHEETS_API_URL` | URL `/exec` ข้อ 2 |
| Secret | `SHEETS_API_KEY` | รหัสเดียวกับ `API_KEY` |
| Variable | `SHEET_URL` | ลิงก์ Google Sheet (ไว้ให้ปุ่มเปิด Sheet) |

จากนั้น push หรือรัน workflow **Deploy Next.js site to Pages** ใหม่

## 4) ใช้บนมือถือ
เปิด `https://nae0000.github.io/Pms/` แล้ว
- iPhone (Safari): แชร์ > เพิ่มไปที่หน้าจอโฮม
- Android (Chrome): เมนู ⋮ > ติดตั้งแอป

## รันในเครื่อง
สร้าง `.env.local`:
```
NEXT_PUBLIC_SHEETS_API_URL=...
NEXT_PUBLIC_SHEETS_API_KEY=...
NEXT_PUBLIC_SHEET_URL=...
```

## หมายเหตุ
- แถวที่ 1 ของแต่ละแท็บคือชื่อคอลัมน์ที่แอปใช้ **ห้ามแก้** (แถวที่ 2 เป็นป้ายภาษาไทย) แก้ข้อมูลในแถว 3 ลงไปได้ตรงๆ
- `API_KEY` ฝังอยู่ในเว็บ (เป็นเว็บ static) จึงเป็นแค่การกันคนสุ่มเข้าถึง ไม่ใช่ระบบล็อกอิน อย่าแชร์ URL เว็บให้คนที่ไม่ไว้ใจ
- ถ้าแก้โค้ด Apps Script ต้อง Deploy > Manage deployments > แก้เวอร์ชันใหม่ ถึงจะมีผล

## แก้ข้อมูลห้อง / ใส่รูปใน Google Sheet
- แท็บ `Rooms` แก้ตรงๆ ได้ (แถวที่ 3 ลงไป): ชื่อห้อง, ประเภท, ค่าเช่า, สถานะ (dropdown), ผู้เช่า, เงินประกัน, ชั้น, ขนาด, สิ่งอำนวยความสะดวก, หมายเหตุ
- **รูปห้อง** คอลัมน์ `image`: วางลิงก์รูป (https://...) หรือลิงก์ Google Drive ได้เลย
  (ไฟล์ใน Drive ต้องตั้งแชร์เป็น "Anyone with the link") แอปแปลงลิงก์ให้เอง
  หรืออัปโหลดรูปจากหน้าห้องพักในแอปก็ได้
- แอปรีเฟรชข้อมูลอัตโนมัติเมื่อเปิดกลับมา หรือกดปุ่ม ↻ บนแถบด้านบน

## ค่าเช่ารายเดือน
หน้า "ค่าเช่า" ในแอปแสดงห้องที่มีผู้เช่า (สถานะ occupied) ว่าเดือนนั้นจ่ายแล้ว/รอจ่าย/เกินกำหนด
กด "รับชำระ" เพื่อบันทึกรายการ Rent ลงแท็บ `Transactions` วันครบกำหนดอ่านจากคอลัมน์ `due_day` ของผู้เช่า (ไม่ใส่ = วันที่ 5)
ถ้ามีคนยกเลิกรายการจะถูกตั้งสถานะ Cancelled (ไม่ลบแถว)

> ถ้าแก้ `Code.gs`: วางโค้ดใหม่ > รัน `setup` > Deploy > Manage deployments > ดินสอ > Version: New version > Deploy (URL เดิม)

## ข้อมูลที่เชื่อมกัน (อ้างอิงด้วย "ชื่อ")
| แท็บ | คอลัมน์ | ต้องตรงกับ |
|---|---|---|
| Rooms | `tenant` | `name` ในแท็บ Tenants |
| Tenants | `room` | `name` ในแท็บ Rooms |
| Transactions | `room` | `name` ในแท็บ Rooms |

แก้ผ่านแอป: ย้ายผู้เช่า / เปลี่ยนชื่อห้อง / ลบผู้เช่า แอปอัปเดตทุกแท็บที่เกี่ยวข้องให้เอง
แก้ใน Sheet โดยตรง: ไปหน้า **ตรวจสอบข้อมูล** ในแอป (หรือกดตัวเลขเตือนบนแถบสถานะ) เพื่อดูชื่อที่ซ้ำ/ไม่ตรง และกด "เชื่อมข้อมูลทั้งหมด"

> Apps Script ของ Google บางครั้งตอบช้าหรือตอบ error ทั้งที่บันทึกสำเร็จแล้ว แอปจึงลองซ้ำและโหลดข้อมูลล่าสุดมาตรวจให้

## ดึงลูกค้าจากแบบสอบถามอัตโนมัติ
ลิสต์คำตอบแบบสอบถาม (Google Form) คือรายชื่อลูกค้าทั้งเก่าและใหม่ แอปดึงเข้าแท็บ `Tenants` เองทุกครั้งที่เปิด (ห่างกัน ≥30 นาที) หรือกดปุ่ม "ดึงจากแบบสอบถาม" ในหน้าผู้เช่า
- จับคู่คนด้วย **ชื่อ-นามสกุล** คนที่มีอยู่แล้วจะ **เติมเฉพาะช่องที่ว่าง** ไม่เขียนทับสิ่งที่คุณกรอกเอง
- คำตอบล่าสุดของแต่ละห้อง = Active, คำตอบเก่ากว่าของห้องเดียวกัน = Past
- เลขห้องจัดเป็นรูปแบบเดียว (`56/853`) เช่น "56 / 853", "56853", "853" -> `56/853`
- วันเข้าพัก/หมดสัญญา/ย้ายออกจริง กรอกทีหลังในแอป (หน้าผู้เช่า > แก้ไข) หรือใน Sheet (`start_date`, `contract_end`, `move_out_date`)
- ใส่ `move_out_date` (วันที่ผ่านมาแล้ว) = ย้ายออกแล้ว สถานะเป็น Past และห้องว่าง
- ถ้าเปลี่ยนลิสต์แบบสอบถาม ให้แก้ `FORM_SHEET_ID` / `FORM_GID` ใน `Code.gs`

## นำเข้าเฉพาะห้องของเรา
แบบสอบถามมีลูกค้าของห้องเจ้าของอื่นด้วย การดึงอัตโนมัติจึงนำเข้า **เฉพาะลูกค้าของห้องที่อยู่ในแท็บ `Rooms`** เท่านั้น (เทียบจากเลขห้อง 56/853 = 853) ถ้ามีห้องใหม่ ให้เพิ่มในแท็บ Rooms ก่อน แล้วลูกค้าของห้องนั้นจะถูกดึงเข้ามาตอนซิงค์ครั้งถัดไป

## ผ่อนห้อง (ยอดกู้ / ผ่อนไปแล้วกี่งวด)
หน้า "ผ่อนห้อง" ในแอป (เมนูข้าง หรือปุ่ม "ตารางผ่อนห้อง" ในหน้าห้องพัก) มีช่องกรอกแยกแต่ละห้อง: ยอดกู้, ค่างวด/เดือน, ผ่อนทั้งหมดกี่งวด, วันเริ่มผ่อน, ผ่อนไปแล้วกี่งวด (ปุ่ม +1 งวด) แก้แล้วบันทึกลงแท็บ `Rooms` อัตโนมัติ
การ์ดห้องแสดง ยอดกู้ / ผ่อนไปแล้ว เป็นหลอดเขียว พร้อมสถานะ (กำลังผ่อน / ผ่อนครบแล้ว / ยังไม่ได้กรอก)
คอลัมน์ใหม่ `loan_amount` (ยอดกู้) ต้องวางโค้ด `Code.gs` ใหม่ > รัน `setup` > Deploy เวอร์ชันใหม่ก่อน ยอดกู้จึงจะถูกเก็บ/อ่านจาก Sheet (ค่างวด/จำนวนงวด/วันเริ่ม/งวดที่ผ่อนแล้ว ใช้ได้เลยไม่ต้องรอ)

## ตารางการผ่อนรายเดือน (แท็บ LoanPayments)
หน้า "ผ่อนห้อง" มี "ตารางการผ่อน" พับได้ต่อห้อง (เดือน / งวดละ / เงินต้น / ดอกเบี้ย / เงินทบ) เก็บในแท็บ `LoanPayments` ของ Sheet
- ช่อง **เงินทบ** = เงินต้นที่ตัดจริงในเดือนนั้น (รวมค่างวดแล้ว) ถ้าว่างใช้ช่อง **เงินต้น**; จ่ายจริง = เงินต้นที่ตัด + ดอกเบี้ย
- คัดลอกตารางจาก Excel/Google Sheet แล้วกด "วางตารางจาก Excel" (ข้ามเดือนที่มีอยู่แล้ว) หรือเพิ่ม/แก้/ลบทีละงวดในแอป
- ถ้ามีตาราง การ์ดห้องจะนับงวด/เงินที่ผ่อนแล้ว/เงินต้นคงเหลือจากตารางนี้ (ต้องใส่ยอดกู้ ถึงจะเห็นหลอดความคืบหน้าและ "ผ่อนครบแล้ว")
- คอลัมน์ `room` ต้องตรงกับชื่อห้องในแท็บ Rooms
- ต้องวางโค้ด `Code.gs` ใหม่ > รัน `setup` (สร้างแท็บ LoanPayments) > Deploy เวอร์ชันใหม่ก่อนจึงจะบันทึกตารางลง Sheet ได้
